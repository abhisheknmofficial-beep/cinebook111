1. Searching Algorithms

search.py

Linear Search: O(n) scan used for multi-field movie query matches.
Binary Search: O(log n) divide-and-conquer on sorted movie IDs and dates.

Array: [101, 104, 109, 115, 120, 134, 150]
Binary Search for 115:
• mid = 115 -> MATCH in 1 iteration! (Best case: O(1))
Time Complexity: O(log n) | Space: O(1)

2. Sorting Algorithms

sorting.py

Merge Sort: Stable divide-and-conquer O(n log n). Used for ratings & release dates where equal scores preserve secondary order.
Quick Sort: In-place partitioning O(n log n). Used for ticket prices.

Merge Sort: splits -> left half, right half -> merge in O(n)
Quick Sort: Lomuto pivot partition -> recursive subarrays
Stability: Merge Sort (Stable) | Quick Sort (Unstable)

3. Hashing & Separate Chaining

hashing.py

Implements ChainingHashTable with DJB2 polynomial hashing and dynamic bucket array resizing when load factor > 0.75.

Hash Formula: index = abs(hash(key)) % capacity
Collision: Chained linked list at bucket[index]
Complexity: Avg O(1) insert/lookup | Space: O(n + cap)

4. 2D Seat Matrix & Allocation

seat_allocation.py

Represents auditorium as matrix[R][C] with O(1) coordinate lookups and a Sliding Window algorithm for adjacent seat bookings.

Window Size = k (requested tickets)
Priority: Middle row outward (center-screen cinematic angle)
Collision Prevention: Hash Set verification O(k)

5. Relationship Graph

graph.py

Models entertainment domain as a Multi-Tier Directed Graph:
Movie ──> Theatre ──> Screen ──> Show ──> Seats

Traversal Algorithms:
• BFS: Layer-by-layer discovery of shows in a city in O(V + E)
• DFS: Full lineage path reservation tracing in O(V + E)

6. FIFO Booking Queue

queue.py

Buffers concurrent ticket checkout transactions in a First-In, First-Out order to guarantee zero race conditions.

Enqueue: O(1) rear append
Dequeue: O(1) front pop
Fairness: FCFS order during flash sales
